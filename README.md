# Embedded-projects

本项目基于 **STM32** 和 **ESP32** 系列单片机开发，支持以下两个开发平台：

- **Keil MDK**：用于 STM32 开发
- **PlatformIO**：用于 ESP32 开发

## 硬件支持

- STM32 系列
- ESP32 系列

## 快速开始

- **Keil**：打开 `keil_project` 目录下的 `.uvprojx` 工程文件，编译下载即可。
- **PlatformIO**：在 VS Code 中打开本项目，根据 `platformio.ini` 选择对应环境，点击 Build / Upload 即可。
